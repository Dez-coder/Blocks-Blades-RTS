СТРУКТУРА ФАЙЛОВ ДЛЯ СВОИХ НПС (GeckoLib)
==========================================

Закинь свои файлы ровно по этим путям (имена менять не нужно):

1) Модель (Blockbench -> "Export Bedrock Geometry"):
   src/main/resources/assets/blocks_blades/geo/npc.geo.json
   (одна модель на всех: и жителей, и воинов)

2) Анимации (Blockbench -> "Export Bedrock Animations"):
   src/main/resources/assets/blocks_blades/animations/npc.animation.json
   (один файл анимаций на всех)

3) Текстуры (PNG) — кладутся в:
   src/main/resources/assets/blocks_blades/textures/entity/

   ИМЕНА ФАЙЛОВ (важно, они уже прошиты в коде):

   Профессии жителей (RTS-профессия):
     npc.png              - базовый житель / без профессии
     npc_miner.png        - шахтёр
     npc_lumberjack.png   - лесоруб
     npc_farmer.png       - фермер

   Профессии ванильных жителей (если профессия не из RTS):
     npc_<vanilla>.png    - например npc_librarian.png, npc_cleric.png,
                            npc_butcher.png, npc_toolsmith.png и т.д.
                            (берётся путь ванильной профессии)
     prof "none" и "nitwit" -> npc.png

   Воины:
     npc_warrior.png      - воин (ближний бой)
     npc_arbalest.png     - арбалетчик (дальний бой)
     npc_summoner.png     - призыватель (магия)

ОБЯЗАТЕЛЬНЫЕ ИМЕНА АНИМАЦИЙ в npc.animation.json:
  idle      - спокойное стояние (зацикленная)
  walk      - ходьба (зацикленная)
  run       - бег (зацикленная)
  attack    - атака (одиночная) — запускается автоматически у воинов
  magic     - каст/магия (одиночная) — запускается автоматически у призывателя
  rejected  - «работает»: копает/рубит (зацикленная)
  talk2     - разговор (зацикленная)
  smeh      - смех (зацикленная)

Сущности:
  blocks_blades:villager_npc — житель
  blocks_blades:warrior_npc  — воин
  blocks_blades:arbalest_npc — арбалетчик
  blocks_blades:summoner_npc — призыватель

Как это работает:
- Житель — наследник обычного жителя, воины — наследники
  поборника/грабителя/заклинателя. Поэтому все задачи, профессии, заказы,
  бой и сохранения работают как раньше.
- "rejected" играется ТОЛЬКО пока НПС реально ломает/рубит блок (когда он уже
  подошёл вплотную и бьёт). Пока он идёт к блоку — играется walk/run.
- Иначе: идёт -> walk, бежит -> run, стоит -> idle.
- Воины при атаке автоматически проигрывают "attack", призыватель — "magic".
- «Своя жизнь»: эмоции НЕ играются случайно. Пока житель идёт — играется
  ТОЛЬКО walk/run. Разговор возможен, только когда житель стоит на месте и
  рядом (в радиусе ~2 блоков) есть другой свободный житель: тогда оба
  останавливаются и разворачиваются строго друг к другу.
- Диалог идёт ПО ОЧЕРЕДИ, а не одновременно: сначала говорит один (talk2),
  второй в это время «слушает» (idle), затем меняются. Время от времени оба
  разом смеются (smeh), после чего беседа может закончиться или продолжиться.
- Других «левых» анимаций (sit и т.п.) жители не используют.
- Анимации можно запускать вручную из кода:
    ((RTSNpc) entity).triggerAnim("main", "attack");
    ((RTSNpc) entity).triggerAnim("main", "magic");

Заготовки geo/animation уже лежат — просто замени их содержимое.
Текстуры (PNG) нужно добавить самому — бинарный PNG через текст не создать.
Если какой-то текстуры нет, GeckoLib покажет стандартную «missing» заглушку.
